# 対応OS一覧

| OS      | 対応バージョン | スマートフォン | タブレット | 対応状況 |
| ------- | -------------- | -------------- | ---------- | -------- |
| iOS     | 15.1 以降      | ○（iPhone）    | ○（iPad）  | 対応     |
| Android | 7.0 以降       | ○              | ○          | 対応     |

<br />

## 運用ルール

- Expo SDK 54の最小対応OS（Android 7.0以降、iOS 15.1以降）をサポート対象とします。
- 原則として、各OSの最新安定版および主要な利用バージョンで動作確認を実施します。
- OS提供元のセキュリティ更新が終了したバージョンは、上記範囲内でもサポート対象外とする場合があります。
- Root化またはJailbreakされた端末、ベータ版OS、独自に改変されたOSはサポート対象外です。
- macOS、WindowsおよびWebブラウザでの利用は、本アプリのサポート対象外です。
- Expo SDKの更新時、OSのメジャーバージョン更新時、または少なくとも3か月ごとに内容を見直します。
