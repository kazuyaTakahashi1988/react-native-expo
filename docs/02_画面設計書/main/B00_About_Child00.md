## 画面項目

#### ヘッダー

| 項目名       | 説明                                                               | 備考 |
| ------------ | ------------------------------------------------------------------ | ---- |
| 共通ヘッダー | 画面タイトルが表示されてる共通ヘッダー。                           |      |
| ネストタブ   | About 画面用の nav リスト（Child00 ~ Child02）が並んだネストタブ。 |      |

#### コンテンツ

| 項目名       | 説明                                         | 備考 |
| ------------ | -------------------------------------------- | ---- |
| 画面タイトル | 画面タイトル（サブタイトル含む）のテキスト。 |      |

<br />

| 項目名                                     | 説明                                                                                                      | 備考 |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------- | ---- |
| Basic ダイアログを開くボタン               | タイトル、本文、閉じるボタン、イベントボタンを持つ Basic ダイアログを表示するボタン。                     |      |
| Not BackGroundPress ダイアログを開くボタン | 背景タップでは閉じない Not BackGroundPress ダイアログを表示するボタン。                                   |      |
| Long Contents ダイアログを開くボタン       | スクロール可能な長い本文を持つ Long Contents ダイアログを表示するボタン。                                 |      |
| Long Contents Only ダイアログを開くボタン  | タイトルとボタンを持たず、スクロール可能な本文のみのダイアログを表示するボタン。                          |      |
| showDialog関数で ダイアログを開くボタン    | `showDialog` 関数を用いて、タイトル、本文、閉じるボタン、イベントボタンを持つダイアログを表示するボタン。 |      |

<br />

| 項目名              | 説明                                 | 備考 |
| ------------------- | ------------------------------------ | ---- |
| 各ダイアログ（×５） | 上述のボタンに対応する各ダイアログ。 |      |

#### フッター

| 項目名       | 説明                                              | 備考 |
| ------------ | ------------------------------------------------- | ---- |
| 共通フッター | main 画面用（メインタブが並んだ）の共通フッター。 |      |
