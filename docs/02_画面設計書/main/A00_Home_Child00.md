#### コンテンツ

| 項目名       | 説明                                         | 備考 |
| ------------ | -------------------------------------------- | ---- |
| 画面タイトル | 画面タイトル（サブタイトル含む）のテキスト。 |      |

<br />

| 項目名                  | 説明                                                                                                                                                         | 備考       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------- |
| 各入力フォーム          | 送信時にバリデーションを行う。エラー発生後は入力値の変更ごとにバリデーションを再検証し、正常になった項目のエラー表示を解消する。                             |            |
| ー お名前               | テキストインプット項目。<br />未入力、2文字未満、51文字以上の場合に、それぞれエラー文言「必須項目だよ。」「2文字以上にしてね」「最大50文字だよ」を表示する。 | 必須項目。 |
| ー よく視聴するジャンル | チェックボックス項目。<br />未選択または選択数が2つ未満の場合に、それぞれエラー文言「必須項目だよ。」「２つ以上選択してください。」を表示する。              | 必須項目。 |
| ー お問い合わせ方法     | ラジオボタン項目。<br />未選択の場合にエラー文言「必須項目だよ。」を表示する。                                                                               | 必須項目。 |
| ー お支払い方法         | スイッチボタン（ラジオボタン）項目。 <br />未選択の場合にエラー文言「必須項目だよ。」を表示する。                                                            | 必須項目。 |
| ー テーマ色の選択       | セレクトボックス項目。 <br />未選択の場合にエラー文言「必須項目だよ。」を表示する。                                                                          | 必須項目。 |
| ー 都道府県             | セレクトカスタムボックス項目。 <br />未選択の場合にエラー文言「必須項目だよ。」を表示する。                                                                  | 必須項目。 |
| ー ご相談の内容         | テキストエリア項目 。<br />未入力、2文字未満、51文字以上の場合に、それぞれエラー文言「必須項目だよ。」「2文字以上にしてね」「最大50文字だよ」を表示する。    | 必須項目。 |
| Submit ボタン           | バリデーションを行い、正常ならフォーム内容を `Submitted values` エリアに一覧表示するボタン。                                                                 |            |
| Reset ボタン            | 全入力値とバリデーションエラーを初期化するボタン。                                                                                                           |            |
