<br />

| 項目名                                       | 説明                                                                                      | 備考                        |
| -------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------- |
| カテゴリー選択フォーム                       | 記事の絞り込み条件を選択するチェックボックス項目。                                        | 記事取得後は非活性。        |
| ー カテゴリー01                              | カテゴリー01_A ~ カテゴリー01_E から選択する。                                            |                             |
| ー カテゴリー02                              | カテゴリー02_A ~ カテゴリー02_E から選択する。                                            |                             |
| ー カテゴリー03                              | カテゴリー03_A ~ カテゴリー03_E から選択する。                                            |                             |
| 選択したカテゴリーで記事を絞り込み検索ボタン | 選択したカテゴリーを条件として記事取得 API を実行するボタン。未選択の場合は全件取得する。 | 記事取得後は非活性。        |
| 取得件数                                     | 取得した記事の件数を表示する。                                                            |                             |
| 記事一覧                                     | 取得した記事を一覧表示するエリア。                                                        | 通常時は非表示。            |
| ー 記事 ID                                   | 取得した記事の ID を表示する。                                                            |                             |
| ー 記事タイトル                              | 取得した記事のタイトルを表示する。                                                        |                             |
| ー カテゴリー                                | 取得した記事に紐づくカテゴリー01 ~ カテゴリー03を表示する。                               |                             |
| ー 記事へ飛ぶボタン                          | 取得した記事のリンクへ外部遷移するボタン。                                                |                             |
| Reset ボタン                                 | 全カテゴリー選択値と記事一覧表示を初期化するボタン。                                      | 各ボタンも非活性 → 活性に。 |
