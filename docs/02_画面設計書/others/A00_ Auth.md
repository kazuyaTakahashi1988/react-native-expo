# Auth 画面設計書

Auth の画面設計書です。

<br />

## 画面デザイン

- [Figma（※ ダミー）](https://)

<br />

## 画面項目

#### ヘッダー

| 項目名       | 説明                                                                                       | 備考 |
| ------------ | ------------------------------------------------------------------------------------------ | ---- |
| 共通ヘッダー | 画面タイトルが表示されてる共通ヘッダー。（『戻る』ボタン、Information 画面遷移ボタンあり） |      |

#### コンテンツ

| 項目名       | 説明                                         | 備考 |
| ------------ | -------------------------------------------- | ---- |
| 画面タイトル | 画面タイトル（サブタイトル含む）のテキスト。 |      |

<br />

| 項目名                 | 説明                                                    | 備考               |
| ---------------------- | ------------------------------------------------------- | ------------------ |
| 認証操作タブ           | Sign In、Sign Up、Verify の各フォームを切り替えるタブ。 | 認証済みなら非活性 |
| 成功・エラーメッセージ | 各認証操作の結果または認証状態の取得エラーを表示する。  | 通常時は非表示。   |

<br />

| 項目名            | 説明                                                                                                                                                                      | 備考               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Sign In フォーム  | メールアドレスとパスワードを用いて Sign In を行うフォーム。                                                                                                               | 未認証時のみ表示。 |
| ー email          | メールアドレスのテキストインプット項目。未入力またはメールアドレス形式でない場合に、それぞれエラー文言「必須項目です。」「Emailアドレスを入力してください。」を表示する。 | 必須項目。         |
| ー password       | パスワードのテキストインプット項目。入力値をマスクする。未入力の場合にエラー文言「必須項目です。」を表示する。                                                            | 必須項目。         |
| ー Sign In ボタン | バリデーションを行い、正常なら Sign In を実行するボタン。                                                                                                                 |                    |
| ー Reset ボタン   | Sign In フォームの全入力値とバリデーションエラーを初期化するボタン。                                                                                                      |                    |

<br />

| 項目名            | 説明                                                                                                                                                                      | 備考               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| Sign Up フォーム  | メールアドレスとパスワードを用いて Sign Up を行うフォーム。                                                                                                               | 未認証時のみ表示。 |
| ー email          | メールアドレスのテキストインプット項目。未入力またはメールアドレス形式でない場合に、それぞれエラー文言「必須項目です。」「Emailアドレスを入力してください。」を表示する。 | 必須項目。         |
| ー password       | パスワードのテキストインプット項目。入力値をマスクする。未入力の場合にエラー文言「必須項目です。」を表示する。                                                            | 必須項目。         |
| ー Sign Up ボタン | バリデーションを行い、正常なら Sign Up を実行するボタン。                                                                                                                 |                    |
| ー Reset ボタン   | Sign Up フォームの全入力値とバリデーションエラーを初期化するボタン。                                                                                                      |                    |

<br />

| 項目名              | 説明                                                                                                                                                                      | 備考               |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |

| ー verificationCode | 認証コードのテキストインプット項目。入力値をマスクする。未入力の場合にエラー文言「必須項目です。」を表示する。                                                            | 必須項目。         |
| ー email            | メールアドレスのテキストインプット項目。未入力またはメールアドレス形式でない場合に、それぞれエラー文言「必須項目です。」「Emailアドレスを入力してください。」を表示する。 | 必須項目。         |
