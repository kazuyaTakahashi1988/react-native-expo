### 補足

- `main 画面`は、メインタブで切り替える画面です。`Home` を初期表示画面とします。
- `others 画面`は、メインタブ対象外となるスタック画面です。ヘッダーの戻る操作で遷移元の画面へ戻ります。
- `AXX`、`BXX`、`CXX` は画面グループを表す見出し行であり、単独の画面およびディープリンクは持ちません。
- ディープリンク欄にはURLのパス部分を記載しています（ルートおよびURLプレフィックスは環境変数によって異なります）。
- 現時点では認証状態に応じた画面ガードおよびリダイレクトを実装していないため、一覧に記載した各画面は公開画面として扱います。
