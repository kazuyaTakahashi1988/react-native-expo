# About > Child02 詳細設計書

About > Child02 の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名                   | 説明                                                                                                                                             | 備考 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| フォーム初期化           | 全入力値を初期化する。                                                                                                                           |      |
| ストア値の取得および出力 | Redux ストアから exampleString と exampleFlag を取得する。<br />exampleString は文字列、exampleFlag は「true/false」として各出力箇所に表示する。 |      |

#### イベント操作時

| 項目名                 | 説明                                                                                                                                                          | 備考 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| テキストインプット入力 | 入力値の変更ごとに exampleString を更新する。<br />更新後の文字列を出力箇所に反映する。                                                                       |      |
| スイッチボタン変更     | checked の変更ごとに exampleFlag を更新する。<br />更新後の真偽値と対応するラベル（noActive or Active）を表示する。<br />更新後の文字列を出力箇所に反映する。 |      |

<br />

## 備考

- Redux Toolkit のストア更新と React Redux の `useSelector` による再描画を確認するためのサンプル。
