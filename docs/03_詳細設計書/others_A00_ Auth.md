# Auth 詳細設計書

Auth の詳細設計書です。

<br />

## 詳細項目

#### アクセス時

| 項目名                 | 説明                                                                                                                                       | 備考 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| フォーム初期化         | 全入力値を初期化、デフォルトでSign In タブが選択状態になってること。                                                                       |      |
| 認証状態による表示制御 | 認証確認中は各フォームを非表示、認証操作タブを非活性にする。<br />未認証時は選択中のフォーム、認証済みの場合は Sign Out ボタンを表示する。 |      |
| 認証状態取得エラー     | 認証状態が error かつエラー情報がある場合はエラーメッセージを表示する。                                                                    |      |

#### イベント操作時

| 項目名           | 説明                                                                                                          | 備考 |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ---- |
| 認証操作タブ押下 | 選択した Sign In、Sign Up、Verify のフォームを表示。<br />認証操作の結果（成功/失敗）メッセージを初期化する。 |      |

<br />

| 項目名             | 説明                                                                                                                                                                                       | 備考 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| Sign In ボタン押下 | 必須項目とメールアドレス形式のバリデーションを行う。正常ならローディングを表示し、Amazon Cognito の Sign In を実行する。                                                                   |      |
| ー Sign In 成功    | Sign In 完了時は「Sign In 成功、ログイン済みだよ！」、追加の Verify が必要な場合は「Sign In にはまだ追加手順（Verify）が必要だよ！」を表示する。フォームを初期化し、認証状態を再取得する。 |      |
| ー Sign In 失敗    | 取得したエラーメッセージを表示する。エラーが Error 型でない場合は「Sign In に失敗したよ...」を表示する。                                                                                   |      |
| ー 処理完了        | 成功・失敗にかかわらずローディングを非表示にする。                                                                                                                                         |      |
| Reset ボタン押下   | フォームの全入力値とバリデーションエラーを初期化する。                                                                                                                                     |      |

<br />

| 項目名             | 説明                                                                                                                                                                                                                                 | 備考 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| Sign Up ボタン押下 | 必須項目とメールアドレス形式のバリデーションを行う。正常ならローディングを表示し、Amazon Cognito の Sign Up を実行する。                                                                                                             |      |
| ー Sign Up 成功    | Verify が不要な場合は Sign In タブへ切り替えて「Sign Up 成功! Sign In しよう！」を表示する。Verify が必要な場合は Verify タブへ切り替えて「OK！ Verify用のコードをメールで送ったから確認してね！」を表示する。フォームを初期化する。 |      |
| ー Sign Up 失敗    | 取得したエラーメッセージを表示する。エラーが Error 型でない場合は「Sign Up に失敗したよ...」を表示する。                                                                                                                             |      |
| ー 処理完了        | 成功・失敗にかかわらずローディングを非表示にする。                                                                                                                                                                                   |      |
| Reset ボタン押下   | フォームの全入力値とバリデーションエラーを初期化する。                                                                                                                                                                               |      |

<br />

| 項目名            | 説明                                                                                                                    | 備考 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------- | ---- |
| Verify ボタン押下 | 必須項目とメールアドレス形式のバリデーションを行う。正常ならローディングを表示し、Amazon Cognito の Verify を実行する。 |      |
| ー Verify 成功    | Sign In タブへ切り替えて「Verify 完了、Sign In できるよ！」を表示し、フォームを初期化する。                             |      |
| ー Verify 失敗    | 取得したエラーメッセージを表示する。エラーが Error 型でない場合は「Verify に失敗したよ...」を表示する。                 |      |
| ー 処理完了       | 成功・失敗にかかわらずローディングを非表示にする。                                                                      |      |
| Reset ボタン押下  | フォームの全入力値とバリデーションエラーを初期化する。                                                                  |      |

<br />

| 項目名              | 説明                                                                                                      | 備考 |
| ------------------- | --------------------------------------------------------------------------------------------------------- | ---- |
| Sign Out ボタン押下 | ローディングを表示し、Amazon Cognito の Sign Out を実行する。                                             |      |
| ー Sign Out 成功    | 「正常に Sign Out したよ！」を表示し、認証状態を再取得する。                                              |      |
| ー Sign Out 失敗    | 取得したエラーメッセージを表示する。エラーが Error 型でない場合は「Sign Out に失敗したよ...」を表示する。 |      |
| ー 処理完了         | 成功・失敗にかかわらずローディングを非表示にする。                                                        |      |

## 備考

- AWS Amplify を介した Amazon Cognito の Sign In、Sign Up、Verify、Sign Out と認証状態に応じた表示制御を確認するためのサンプル。
