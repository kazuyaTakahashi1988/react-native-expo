## 詳細項目

#### アクセス時

| 項目名                   | 説明                   | 備考 |
| ------------------------ | ---------------------- | ---- |
| フォーム（選択値）初期化 | 全入力値を初期化する。 |      |

#### イベント操作時

| 項目名                                           | 説明                                                                                                                                                          | 備考 |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 選択したカテゴリーで記事を絞り込み検索ボタン押下 | カテゴリー01 ~ カテゴリー03の選択値を配列形式のクエリパラメータに設定し、記事取得 API（`GET /wp-json/wp/v2/org_api`）を実行する。未選択の場合は全件取得する。 |      |
| ー API 成功                                      | レスポンスから取得件数、記事 ID、記事タイトル、各カテゴリー、記事リンクを取得して記事一覧に表示し、カテゴリー選択フォームと検索ボタンを非活性にする。         |      |
| ー API 失敗                                      | コンソールにエラーを出力する。                                                                                                                                |      |
| 記事へ飛ぶボタン押下                             | 対象記事のリンクへ外部遷移する。                                                                                                                              |      |
| Reset ボタン押下                                 | フォーム（選択値）を初期化し、記事一覧を非表示にする。                                                                                                        |      |
