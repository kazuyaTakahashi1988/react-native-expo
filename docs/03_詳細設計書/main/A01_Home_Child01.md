#### イベント操作時

| 項目名               | 説明                                                                                                      | 備考 |
| -------------------- | --------------------------------------------------------------------------------------------------------- | ---- |
| 記事取得ボタン押下   | 記事取得 API（`GET /wp-json/wp/v2/posts`）を実行する。                                                    |      |
| ー API 成功          | レスポンスから記事 ID、記事タイトル、記事リンクを取得して記事一覧に表示し、記事取得ボタンを非活性にする。 |      |
| ー API 失敗          | コンソールにエラーを出力する。                                                                            |      |
| 記事へ飛ぶボタン押下 | 対象記事のリンクへ外部遷移する。                                                                          |      |
