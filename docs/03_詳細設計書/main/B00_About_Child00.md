#### イベント操作時

| 項目名                                         | 説明                                                                                                          | 備考 |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | ---- |
| Basic ダイアログを開くボタン押下               | Basic ダイアログを表示する。                                                                                  |      |
| Not BackGroundPress ダイアログを開くボタン押下 | 背景タップによる非表示を無効にした Not BackGroundPress ダイアログを表示する。                                 |      |
| Long Contents ダイアログを開くボタン押下       | 本文を縦スクロールできる Long Contents ダイアログを表示する。                                                 |      |
| Long Contents Only ダイアログを開くボタン押下  | タイトルとボタンを持たず、本文を縦スクロールできるダイアログを表示する。                                      |      |
| showDialog関数で ダイアログを開くボタン押下    | `showDialog` 関数を実行し、ID `id-xxxx`、z-index `1000` のダイアログを表示する。                              |      |
| ー 各背景タップ                                | 表示中のダイアログを閉じる。<br />Not BackGroundPress ダイアログでは何も行わない。                            |      |
| ー 各閉じるボタン押下                          | 表示中のダイアログを閉じる。                                                                                  |      |
| ー 各イベントボタン押下                        | タイトル「Thanks to Tap」、メッセージ「EventButton Tapped!!」のアラートを表示し、表示中のダイアログを閉じる。 |      |
